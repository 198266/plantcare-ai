# PhytoSense AI 🌱

Application intelligente pour identifier, soigner, cultiver et découvrir les plantes grâce à l'intelligence artificielle.

## Objectifs

- Identifier les plantes par photo
- Détecter les problèmes possibles
- Donner des conseils de culture
- Suivre la santé des plantes
- Proposer des informations sur la récolte et l'utilisation

Projet en développement.
